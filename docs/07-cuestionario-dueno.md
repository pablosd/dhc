Este documento tiene dos partes:

1. **Notas para Pablo**: cómo usar el cuestionario y dónde se vuelcan las respuestas.
2. **El cuestionario**: listo para enviar al dueño (copiar desde "Cuestionario" hasta el final).

## Notas para Pablo

- Las preguntas con ★ son **imprescindibles para publicar**. El resto mejora el sitio, pero no lo bloquea.
- Cada pregunta tiene un código (`A1`, `C5`…). Los docs lo usan para marcar lo pendiente, por ejemplo `[TODO D1]`.
- Regla de oro: **si no hay respuesta, no se inventa**. El texto que depende de una respuesta se quita o se reformula.
- Al recibir las respuestas:
  1. Datos del negocio → `src/content/site.ts` (quitar los `// TODO(confirmar)` correspondientes).
  2. Textos afectados → `docs/04-contenido.md` y los diccionarios `en.ts` / `es.ts`.
  3. Servicios y zonas → `docs/01` (tabla de servicios), `docs/05` (palabras clave, `areaServed`).
  4. Marcar la pregunta como respondida en la tabla de seguimiento de abajo.
- El cuestionario está en español. Si el dueño prefiere inglés, se traduce antes de enviarlo.
